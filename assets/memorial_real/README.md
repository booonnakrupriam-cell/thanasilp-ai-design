# ชุดแม่แบบป้ายไว้อาลัยสมจริง (ธนศิลป์)

เว็บไซต์โหลดไฟล์ภาพจริงจากโฟลเดอร์นี้โดยอัตโนมัติ เมื่อมีไฟล์ครบ:

- `manifest.json`
- `royal_violet.png`, `ivory_gold.png`, `heaven_blue.png`, `black_gold.png`, `white_lilies.png`, `blush_rose.png`, `navy_royal.png`, `burgundy_gold.png`, `silk_gold.png`
- `sky_vertical.png`, `ivory_vertical.png`, `black_vertical.png`, `rose_vertical.png`

แหล่งไฟล์คือ `thanasilp_memorial_real_pack_13.zip` ที่สร้างให้ในแชต ห้ามใส่รูปบุคคลจริงของลูกค้าเป็นภาพตัวอย่างสาธารณะ

หากยังไม่มีไฟล์เหล่านี้ หน้าเว็บสามารถรับชุด ZIP ผ่านช่องอัปโหลดแบบเซสชันได้ตามปกติ เมื่อเพิ่มไฟล์ครบใน GitHub แล้ว เว็บจะเปิดแกลเลอรีได้เองโดยไม่ต้องอัปโหลด ZIP ทุกครั้ง
