ธนศิลป์ AI Design (รุ่นฟรี ไม่มีค่า API)

1. ติดตั้ง Python จาก https://www.python.org/downloads/
   ระหว่างติดตั้งติ๊ก Add Python to PATH ถ้ามีตัวเลือก
2. แตกไฟล์ ZIP ลงในโฟลเดอร์บน Windows
3. เปิด CMD ในโฟลเดอร์นี้ แล้วพิมพ์:
   python -m pip install -r requirements.txt
4. ดับเบิลคลิก เปิดโปรแกรม.bat
   หรือพิมพ์ python -m streamlit run app.py
5. เปิดเว็บ http://localhost:8501
6. เลือกประเภทงาน ขนาด สี และอัปโหลดรูปได้ 3 ช่อง
7. คัดลอกคำสั่งที่สร้างได้ แล้วเปิด ChatGPT แนบภาพและส่งคำสั่ง

หมายเหตุ: ไม่มีการส่งไฟล์เข้า ChatGPT อัตโนมัติ และไม่ได้สร้างภาพภายในเว็บ
